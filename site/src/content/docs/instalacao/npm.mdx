Com **Node.js 18+**:

```bash
npm i -g kraa && kraa start
```

O pacote npm é só um instalador. No `postinstall` ele baixa do
[GitHub Release](https://github.com/gustafsilva/kraa/releases) o binário da **mesma
versão** do pacote, confere o SHA-256 contra o `checksums.txt` do release e o instala no
diretório do usuário (sem `sudo`).

## Onde o app fica instalado

| SO | Caminho | Arquitetura |
|---|---|---|
| macOS | `~/Applications/Kraa.app` | universal (arm64 + x64) |
| Windows | `%LOCALAPPDATA%\kraa\kraa.exe` | x64 |
| Linux | `~/.local/share/kraa/kraa` | x64 e arm64 |

## Dependências do sistema

O npm não instala pacotes do sistema. Confira o que o seu SO precisa:

## Se o download falhar

Sem internet no momento do `npm i`, a instalação **não quebra**: o pacote é instalado sem o
binário. Depois, rode:

```bash
kraa install
```

`kraa start` também baixa o binário automaticamente se ele ainda não existir.

## Variáveis de ambiente

| Variável | Efeito |
|---|---|
| `KRAA_SKIP_DOWNLOAD=1` | Pula o download no `postinstall` (útil em CI). |
| `KRAA_REPO` | Repositório `dono/repo` de onde baixar o release (forks). |

## Atualizar e desinstalar

```bash
npm i -g kraa@latest   # atualiza (baixa o binário da nova versão)
kraa stop
npm rm -g kraa         # remove a CLI
```

<Callout type="note">
  O `npm rm` remove só a CLI. Para apagar o app, remova também o diretório da tabela acima e,
  se quiser, a [configuração](/docs/configuracao/arquivo/). Desligue antes o início automático
  com `kraa autostart off`.
</Callout>
