## Atalho global

| SO | Padrão |
|---|---|
| macOS | <Kbd keys={["⌘", "⇧", "Y"]} /> |
| Windows e Linux (X11) | <Kbd keys={["Ctrl", "Shift", "Y"]} /> |

O atalho é configurável pela chave `hotkey` do [config.yaml](/docs/configuracao/arquivo/), com a
sintaxe `CmdOrCtrl+Shift+Y` (`CmdOrCtrl` vira <Kbd keys={["⌘"]} /> no macOS e
<Kbd keys={["Ctrl"]} /> nos demais). Depois de editar, use **Recarregar configuração** na bandeja.

<Callout type="note" title="Atalho em uso por outro app">
  Se o atalho não puder ser registrado, o modal mostra um aviso. Escolha outra combinação em
  `hotkey` ou abra o modal pelo item **Abrir** da bandeja.
</Callout>

No **Wayland** não há atalho global nativo: configure um atalho do sistema que rode
`kraa --trigger` (veja [Linux](/docs/plataformas/linux/#wayland)).

## Dentro do modal

Dá para usar o Kraa inteiro sem o mouse:

| Atalho | Ação |
|---|---|
| digitar | Filtra as ações; se nada combinar, vira uma **instrução livre** |
| <Kbd keys={["↑"]} /> <Kbd keys={["↓"]} /> | Navega pela lista de ações |
| <Kbd keys={["Enter"]} /> | Executa a ação selecionada (ou a instrução livre) |
| <Kbd keys={["←"]} /> <Kbd keys={["→"]} /> | Com o resultado pronto, escolhe entre **Copiar** e **Substituir** |
| <Kbd keys={["Enter"]} /> | Aplica a opção escolhida |
| <Kbd keys={["↑"]} /> | Volta para a lista de ações para tentar outra |
| <Kbd keys={["⌘/Ctrl", "Enter"]} /> | **Substituir** direto, de qualquer lugar |
| <Kbd keys={["⌘/Ctrl", "Shift", "C"]} /> | **Copiar** direto, de qualquer lugar |
| <Kbd keys={["⌘/Ctrl", "["]} /> <Kbd keys={["⌘/Ctrl", "]"]} /> | Navega entre as [versões](/docs/uso/versoes-e-refino/) do resultado |
| <Kbd keys={["⌘/Ctrl", "R"]} /> | **Gerar de novo**: outra alternativa para o mesmo pedido |
| <Kbd keys={["⌘/Ctrl", "L"]} /> | Foca o campo **Refinar** |
| <Kbd keys={["⌘/Ctrl", "D"]} /> | Mostra ou esconde as **Mudanças** (diff) da versão exibida |
| <Kbd keys={["Esc"]} /> | Fecha o modal e cancela o stream em andamento |

Quando o resultado termina, o foco vai sozinho para **Substituir** (ou **Copiar**, se não der para
colar no app de origem): basta apertar <Kbd keys={["Enter"]} />. Se você estiver editando o texto,
o foco fica onde está.

<Callout type="note" title="Teclado ABNT2">
  Os atalhos de versão (<Kbd keys={["⌘/Ctrl", "["]} /> e <Kbd keys={["⌘/Ctrl", "]"]} />) seguem
  os caracteres `[` e `]`: no ABNT2, use as teclas marcadas com `[` e `]`. Eles não disparam junto
  com <Kbd keys={["AltGr"]} />, para não atrapalhar quem digita colchetes com AltGr.
</Callout>

"Substituir" e "Copiar" só agem sobre o resultado **completo**: nunca sobre um stream parcial nem
depois de um erro. Nesse caso, tente de novo.

## Bandeja do sistema

| Item | O que faz |
|---|---|
| Abrir | Abre o modal sem capturar a seleção |
| Editar configuração | Abre o `config.yaml` no editor padrão |
| Recarregar configuração | Relê o arquivo sem reiniciar o app |
| Iniciar com o sistema | Liga/desliga o início automático |
| Sair | Encerra o app |
