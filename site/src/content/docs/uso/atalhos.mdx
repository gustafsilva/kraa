## Atalho global

| SO | Padrão |
|---|---|
| macOS | <Kbd keys={["⌘", "⇧", "Y"]} /> |
| Windows e Linux (X11) | <Kbd keys={["Ctrl", "Shift", "Y"]} /> |

O atalho é configurável pela chave `hotkey` do [config.yaml](/docs/configuracao/arquivo/), com a
sintaxe `CmdOrCtrl+Shift+Y` (`CmdOrCtrl` vira <Kbd keys={["⌘"]} /> no macOS e
<Kbd keys={["Ctrl"]} /> nos demais). Depois de editar, use **Recarregar configuração** na bandeja.

<Callout type="note" title="Atalho em uso por outro app">
  Se o atalho não puder ser registrado, o modal mostra um aviso. Escolha outra combinação em
  `hotkey` ou abra o modal pelo item **Abrir** da bandeja.
</Callout>

No **Wayland** não há atalho global nativo: configure um atalho do sistema que rode
`kraa --trigger` (veja [Linux](/docs/plataformas/linux/#wayland)).

## Dentro do modal

| Atalho | Ação |
|---|---|
| <Kbd keys={["↑"]} /> <Kbd keys={["↓"]} /> | Navega pela lista de ações (digite para filtrar) |
| <Kbd keys={["Enter"]} /> | Executa a ação selecionada ou envia a instrução livre |
| <Kbd keys={["⌘/Ctrl", "Enter"]} /> | **Substituir**: cola o resultado no app de origem |
| <Kbd keys={["⌘/Ctrl", "Shift", "C"]} /> | **Copiar**: copia o resultado para a área de transferência |
| <Kbd keys={["Esc"]} /> | Fecha o modal e cancela o stream em andamento |

"Substituir" e "Copiar" só agem sobre o resultado **completo**: nunca sobre um stream parcial nem
depois de um erro. Nesse caso, tente de novo.

## Bandeja do sistema

| Item | O que faz |
|---|---|
| Abrir | Abre o modal sem capturar a seleção |
| Editar configuração | Abre o `config.yaml` no editor padrão |
| Recarregar configuração | Relê o arquivo sem reiniciar o app |
| Iniciar com o sistema | Liga/desliga o início automático |
| Sair | Encerra o app |
