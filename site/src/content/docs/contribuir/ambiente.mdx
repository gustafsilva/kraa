## Requisitos

- **Go 1.25+** (a versão exata está no `go.mod`)
- **Node.js 22+**
- **CLI do Wails v3**, na versão fixada no `go.mod` (`v3.0.0-beta.26`)
- Um LLM para testar manualmente (Ollama local)

## Primeira execução

<Steps>

1. **Clone o repositório**

   ```bash
   git clone https://github.com/gustafsilva/kraa.git
   cd kraa
   ```

2. **Instale a CLI do Wails**

   ```bash
   go install github.com/wailsapp/wails/v3/cmd/wails3@v3.0.0-beta.26
   ```

   No Linux, adicione `-tags gtk3` ao `go install`.

3. **Instale as dependências do frontend**

   ```bash
   npm --prefix frontend ci
   ```

4. **Rode em modo desenvolvimento**

   ```bash
   wails3 dev
   ```

   Sobe a app com o ícone na bandeja e hot reload do frontend.

</Steps>

## Comandos úteis

| Comando | O que faz |
|---|---|
| `wails3 dev` | App em modo desenvolvimento |
| `wails3 build` | Build de produção (binário em `bin/`) |
| `wails3 generate bindings -ts` | Regenera os bindings TS depois de mudar métodos Go expostos |
| `go test ./...` | Testes do backend |
| `npm --prefix frontend test` | Testes do frontend (Vitest) |
| `npm --prefix npm test` | Testes do instalador e da CLI npm |
| `npm --prefix site run dev` | Este site de documentação |

<Callout type="warning" title="Linux: tag gtk3">
  O Wails beta.26 usa GTK4/WebKitGTK 6.0 por padrão, que não existe no Ubuntu 22.04. O projeto
  compila com a tag `gtk3`. O `wails3 dev`/`build` já aplicam a tag, mas comandos `go` diretos
  precisam dela: `go test -tags gtk3 ./...`, `go vet -tags gtk3 ./...`.
</Callout>
