O **Prompt Improve** é um app de bandeja para macOS, Windows e Linux que melhora o texto
selecionado em qualquer aplicativo usando um LLM compatível com a API OpenAI. Por padrão ele
conversa com o [Ollama](https://ollama.com) rodando na sua máquina.

Um atalho global captura a seleção e abre um modal com ações prontas (melhorar prompt, mais
formal, corrigir gramática, traduzir…) e um campo de instrução livre. O resultado chega em
stream e pode ser **substituído** direto no app de origem ou **copiado**.

```text
 seleciona texto   ──►   ⌘/Ctrl+Shift+Y   ──►   escolhe ação   ──►   resposta em stream
 em qualquer app         (captura a seleção)    ou instrução           │
                                                                       ├─► ⌘/Ctrl+Enter → Substituir
                                                                       └─► ⌘/Ctrl+Shift+C → Copiar
```

## Para quem é

- Quem escreve muitos **prompts** e quer deixá-los mais claros sem abrir outro chat.
- Quem ajusta **mensagens** o dia todo: tom mais formal, texto mais curto, tradução rápida.
- Quem quer tudo isso **local e privado**, com um modelo rodando no próprio computador.

## Requisitos em resumo

| | macOS | Windows | Linux (Ubuntu 22.04+) |
|---|---|---|---|
| LLM | Ollama local ou endpoint OpenAI-compatível | igual | igual |
| Permissões | Acessibilidade | nenhuma | nenhuma |
| Dependências | — | — | `libgtk-3-0`, `libwebkit2gtk-4.1-0`, `xdotool` (X11) |
| Colagem automática | ✓ | ✓ | ✓ no X11 · só "Copiar" no Wayland |
