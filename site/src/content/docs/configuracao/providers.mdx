O Prompt Improve fala com qualquer serviço que implemente a API **Chat Completions** da OpenAI
(`POST {base_url}/chat/completions` com streaming SSE). Basta ajustar o bloco `provider` do
[config.yaml](/docs/configuracao/arquivo/).

## Ollama local (padrão)

```yaml
provider:
  base_url: "http://localhost:11434/v1"
  api_key: ""
  model: "llama3.2"
  timeout_seconds: 60
```

Veja [Ollama](/docs/instalacao/ollama/) para instalar e baixar modelos.

## Ollama Cloud

```yaml
provider:
  base_url: "https://ollama.com/v1"
  api_key: "SUA_CHAVE_AQUI"
  model: "llama3.2"
  timeout_seconds: 60
```

## OpenAI

```yaml
provider:
  base_url: "https://api.openai.com/v1"
  api_key: "SUA_CHAVE_AQUI"
  model: "gpt-4o-mini"
  timeout_seconds: 60
```

## Outros endpoints compatíveis

LM Studio, vLLM, llama.cpp server, OpenRouter e similares funcionam do mesmo jeito: aponte
`base_url` para a raiz `/v1` do serviço e informe o `model`.

<Callout type="tip" title="Não deixe a chave no arquivo">
  Prefira a variável `PROMPT_IMPROVE_API_KEY`: ela sobrescreve `api_key` e nunca é gravada em
  disco.
</Callout>

<Callout type="warning" title="Privacidade">
  Com um provider remoto, o texto selecionado é enviado para esse serviço. Veja
  [Privacidade](/docs/plataformas/privacidade/).
</Callout>
